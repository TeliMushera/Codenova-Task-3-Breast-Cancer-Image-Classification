
# Dataset Instructions

Download the Breast Ultrasound Images Dataset (BUSI) from:

https://www.kaggle.com/datasets/aryashah2k/breast-ultrasound-images-dataset

Extract the dataset into this folder. The notebook searches for
the `benign`, `malignant`, and `normal` image directories.

Segmentation mask files are excluded from image classification.

The dataset is not included in this repository. Refer to the
original dataset source for usage terms and citation information.
